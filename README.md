# Translation Plugin - Penpot beta plugin
Recently received an invite to Penpot's Plugin 🔌 beta and wanted to learn how to build with the plugins API. I've already been using Ollama 🦙, which runs models locally, like Llama3.1, Qwen, or Gemma. 

I thought it would make for a nice learning experience to create a basic translation plugin using both. So far, the result has been a surprisingly fun learning experience, and planning to build out more side projects with this combo. It's still rough and littered with console logs 🙃.
